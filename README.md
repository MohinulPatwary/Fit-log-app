# GYM FIT LOG

### Short Description

This is my my gym fit log next.js app. I built it for my daily gym activity tracing and maintaing my day to day activities. It improving my daily process to decide which workout i need to do today. WHich is burning how much calories also how much time and equipement I need to finish it properly.

### Technologies Used

* Next.js
* Tailwind.css
* DaisyUI
* React Components

### 5 Key Features of the Project

**1. Fully Responsive**

It is fully responive in any device like pc, tablet and mobile.

**2. All Buttons Are Functional**

It all buttons are functional.

**3. Three Pages**

It has total three page one is main display where all data showing, second one is each card details page and third one is My plan list page.

**4. Navbar**

Most important features is it navbar, from where we can route every page and nav or footer is static.

**5. Dynamic Page Routing**

Most important feature is its dynamic page routing.
